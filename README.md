# Task Manager Lab

A minimal, modern, and beautiful task manager web app built with HTML, CSS, and vanilla JavaScript.

## 🚀 Features

- Add new tasks with a single click
- Delete or edit tasks using intuitive buttons
- View total number of tasks using "Show Task Summary"
- Smooth and clean UI with glassmorphism design

## 🛠️ Technologies Used

- HTML5
- CSS3 (Glassmorphism style)
- Vanilla JavaScript (ES6+)

## 🧪 Future Improvements

- Mark tasks as completed
- Store tasks in LocalStorage
- Filter tasks by status (All / Completed / Active)
- Add light/dark mode toggle
