🖥️ Features in Detail
1. The this Keyword in JavaScript
In traditional functions, the this keyword refers to the global object (or window in browsers).

Arrow functions behave differently by referring to the lexical scope of the surrounding context.

2. bind, call, and apply Methods
bind() is used to create a new function with a specific this value.

call() and apply() allow you to call functions with a specified this value and pass arguments differently.

3. Shallow and Deep Copying
Shallow copy: Top-level properties are copied, but nested structures remain references.

Deep copy: Ensures all nested objects and arrays are duplicated.
